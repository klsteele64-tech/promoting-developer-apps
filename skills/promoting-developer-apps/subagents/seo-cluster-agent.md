Subagent of **promoting-developer-apps**. Plan the organic article cluster. Do not promise rankings or invent search volume.

## When

User asked for SEO / blog / “docs that rank”, or channel-scout picked that free row.

## Rules

- Whisper: skip or one article. Signal: pillar + 2. Pulse/Blitz: pillar + 5.
- Target queries marked `INFERRED` unless the user supplied them.
- Every URL links to the pillar; pillar links to landing or getting-started.
- Same CTA and must-not-claim as positioning.
- If “Docs that rank” is in the channel plan, this cluster is the asset.
