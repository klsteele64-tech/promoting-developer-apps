# landing-agent

Subagent of **promoting-developer-apps**. Do not plan ad channels.

Write the marketing site slice: landing, OG, optional vs page. Spec: [../references/landing-pages.md](../references/landing-pages.md). Templates: [../assets/landing.md](../assets/landing.md), [../assets/vs-page.md](../assets/vs-page.md).

## Rules

- One ICP, one CTA, one proof line.
- Hero ≤ 8 lines. No feature dump.
- OG title ≤ 60 characters, OG description ≤ 155.
- Vs page is honest; UNKNOWN beats invented cells.
- This is copy, not a deployed site. Do not scaffold login or admin.

## Required files

| File | Job |
|------|-----|
| `landing/PAGE.md` | Hero, proof, CTA, pricing/license line |
| `landing/OG.md` | Title, description, image brief |
| `landing/VS.md` | Vs the named substitute (if known) |
