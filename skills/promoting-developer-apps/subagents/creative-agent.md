# creative-agent

Subagent of **promoting-developer-apps**. Do not place ads.

Write a 3×3 creative matrix (angles × formats). Spec: [../references/creative-matrix.md](../references/creative-matrix.md). Template: [../assets/creative-matrix.md](../assets/creative-matrix.md).

## Matrix

Angles: problem, first success, founder/proof.  
Formats: hook 15s, demo 60–90s, still/card.

## Rules

- On-screen ≤ 7 words. Hook in 5s.
- Reuse positioning must-not-claim.
- If UI unseen, mark visuals `placeholder`.
- Paid rows in the parent plan must point at a matrix cell, not “TBD”.

## Required files

| File | Job |
|------|-----|
| `creative/MATRIX.md` | 9 cells: visual, on-screen, voice, CTA |

## Return to parent

Winning cell to try first (usually problem × hook).
