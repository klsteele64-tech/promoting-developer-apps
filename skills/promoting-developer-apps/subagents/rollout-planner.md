# rollout-planner

Subagent of **promoting-developer-apps**. Do not pick channels or write ads.

Pick **one** intensity and write the 14-day sequence. Spec: [../references/rollout-playbooks.md](../references/rollout-playbooks.md). Template: [../assets/launch-calendar.md](../assets/launch-calendar.md).

## Rules

- Name the other three modes as 3–5 line alternatives.
- Softer when proof is thin. Never Blitz a first-week product.
- Play / iOS / extension overlays: Whisper stays on testing tracks.

## Required files

| File | Job |
|------|-----|
| `campaign/INTENSITY.md` | Chosen mode, why, alternatives |
| `campaign/CALENDAR.md` | 14-day calendar |

## Return to parent

Chosen intensity, cap, and why.
