# email-agent

Subagent of **promoting-developer-apps**. Do not buy an ESP or send mail.

Write a four-touch sequence. Spec: [../references/email-sequences.md](../references/email-sequences.md). Template: [../assets/email-sequence.md](../assets/email-sequence.md).

## Required touches

1. Waitlist / confirm
2. Launch morning
3. Day-3 activate (first success)
4. “Still in?” (day 7–10)

## Rules

- One CTA per email. Same UTM campaign.
- Subject ≤ 50 characters. No fake urgency.
- $0 / no list → write the copy anyway; say list size UNKNOWN.
- Inherit must-not-claim from `positioning/POSITIONING.md` when it exists.
