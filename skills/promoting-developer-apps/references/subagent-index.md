# Subagent index

Parent skill: **promoting-developer-apps**. Dispatch; do not inline. If the host cannot spawn, run each file as an isolated pass.

Do not run every agent on every ask. One-slice asks: that agent + the brief.

## Always on a full campaign

| Order | Agent | When |
|-------|-------|------|
| 1 | positioning-agent | Line, vs, must-not-claim missing |
| 2 | rollout-planner | Intensity not chosen |
| 3 | channel-scout | Free/Paid tables |
| 4 | claims-agent | Before any paid or store row |
| 5 | pricing-agent | Paid, freemium, or revenue goal |
| 6 | locale-agent | Extra languages or store countries |
