# Apple App Store

Plans only. User pastes into App Store Connect.

| Field | Limit | Rule |
|-------|-------|------|
| Name | 30 | Brand + one job word |
| Subtitle | 30 | Differentiator |
| Keywords | 100 | Commas, no name repeat, no competitor trademarks unless accepted |
| Description | 4000 | First 3 lines sell |
| Icon | 1024×1024 | |
| Screenshots | 6.7" + 6.5" (and iPad if needed) | First two = first success |
| Preview | Optional | video-agent hook |

**Free:** App Store listing (ASO), TestFlight, Product Hunt, Reddit value-first, organic social.

**Paid:** Apple Search Ads only if budget > 0. Exact match category + brand first. No Play UAC here.

Intensity: Whisper = TestFlight; Signal = listing + one stage; Pulse+ = listing experiments + optional ASA.
