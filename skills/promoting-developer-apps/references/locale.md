# Locale and store localization

Use when the product ships in more than one language or country. The parent dispatches **locale-agent**. Plans copy. Does not publish localized listings.

## How many locales

| Intensity | Locales |
|-----------|---------|
| Whisper | Source language only |
| Signal | Source + **one** extra |
| Pulse / Blitz | Source + up to **3** extras |

Default source: English. Extra locales come from intake (countries / languages). Do not invent a 12-language plan.

## What to localize (in this order)

1. Store: name/subtitle/short desc (Play or App Store limits still apply)
2. Landing hero + CTA + OG
3. Email subjects + one-line preview
4. First two screenshot captions

Full docs and long emails only if asked.

## Rules

- Mark unreviewed translation `INFERRED — machine`. Do not claim a native speaker wrote it.
- Must-not-claim list is language-invariant (no health/finance performance claims in any locale).
- Currency and price stay UNKNOWN unless the user gave them. Do not invent regional prices.
- RTL or CJK: note screenshot safe-area and shorter on-screen copy.
- Hand the strings to play-store-agent / app-store-agent / landing-agent / email-agent. Do not replace those packs.

## Priority

Pick extras by: user-named countries, then store country list, then UNKNOWN (ask). One ICP still — do not invent a new audience per language.
