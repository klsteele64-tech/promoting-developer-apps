# SEO cluster

Use when the user wants organic search or the free catalog pick is “Docs that rank”. The parent dispatches **seo-cluster-agent**.

This is a writing plan, not a promise of rankings. Do not invent search volume.

## Size

| Intensity | Cluster |
|-----------|---------|
| Whisper | Skip, or one getting-started article |
| Signal | 1 pillar + 2 supporting |
| Pulse / Blitz | 1 pillar + 5 supporting (6 URLs) |

## Shape

- **Pillar:** the job-to-be-done (`How {ICP} {job} without {substitute}`).
- **Supporting:** one query each — how-to, vs, error/fix, install, comparison, changelog-as-article.
- Every URL: title, H1, target query (`INFERRED` if guessed), 3 internal links, one CTA (same as landing).
- Internals: supporting → pillar → landing or docs first-success. No orphan posts.

## Rules

- Reuse positioning and must-not-claim.
- Do not paste competitor docs.
- “Docs that rank” in the channel plan must point at this cluster, not a vague blog.
- UTM: `utm_medium=organic`, `utm_campaign` = launch slug, `utm_content` = slug.
