# Free advertising and distribution

Organic and no-media-buy channels. Do not put paid placements here.

For each pick include: why this product, asset, CTA, metric, first action this week.

## Launch communities

| Channel | Best for | Asset | Default metric |
|---------|----------|-------|----------------|
| Product Hunt | Consumer/prosumer apps, design-forward SaaS | Hunt page, first comment, maker video | Upvotes, referral signups |
| Hacker News (Show HN) | Technical tools, OSS, infrastructure | Show HN post, repo, demo | Points, GitHub stars, signups |
| BetaList / BetaPage | Pre-launch waitlists | Listing + screenshot set | Waitlist emails |
| AlternativeTo | Displacement of a known tool | "Alternative to X" listing | Profile visits |
| There's An AI For That / similar directories | AI products | Directory card | Referral clicks |
| Uneed / Toolify / SaaSHub / G2 (organic profile) | B2B SaaS | Profile + 3 reviews | Profile views |
| Peerboard / Launching Next | Indie launches | Short listing | Clicks |

## Rules

- Reddit, SO, and groups: contribute first. A dump-and-leave post is not a channel plan.
- Product Hunt + Show HN in the same 24h often splits attention. Stagger unless Blitz.
- Directories without a unique screenshot and one-line differentiation waste the slot.
- Cap picks using the intensity table in SKILL.md.
