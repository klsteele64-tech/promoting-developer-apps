# Claims check

Run before paid or store copy ships.

| Flag | Action |
|------|--------|
| Kids / Families | Extra policy; no interest ads language |
| Health / medical | No outcome claims |
| Finance / crypto | No performance / returns |
| Guaranteed rank, ROAS, CPI | Delete |
| Testimonials / logos | Need confirmation or drop |
| Competitor trademarks in keywords | Drop unless user accepts risk |
| Fake scarcity | Delete |

Output PASS or FAIL. FAIL blocks paid and store rows until rewritten.
