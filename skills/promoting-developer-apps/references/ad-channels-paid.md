# Paid advertising

Media-buy and sponsored placements. Keep this list separate from free channels.

For each pick include: objective, audience, daily cap, creative, CTA, success metric, **kill criterion**.

Never recommend paid spend on a $0 budget. If budget is unknown, propose a $20–50/day test, not a full campaign.

## Search and intent

| Channel | Best for | Typical objective | Notes |
|---------|----------|-------------------|-------|
| Google Ads Search | High-intent keywords ("best X for Y") | Conversions / trial | Exact + phrase first; brand terms if competitors bid |
| Google Ads Display / Demand Gen | Remarketing, visual | Traffic / awareness | Weak for cold B2B tools; use remarketing lists |
| Google YouTube ads | Demo-able products | Views / conversions | 15–30s skippable; hook in 5s |
| Microsoft Ads (Bing) | Cheaper search, older ICP | Conversions | Import Google campaigns; lower volume |
| Apple Search Ads | iOS apps | Installs | Exact match on category + brand |
| Amazon Ads | Products sold on Amazon | Sales | Irrelevant unless listed there |
| App Store search ads (Google UAC / ASA) | Mobile installs | Installs / ROAS | Need store assets + MMP later |

## Social and feed ads

| Channel | Best for | Typical objective | Notes |
|---------|----------|-------------------|-------|
| Meta (Facebook / Instagram) | Consumer, SMB, visual | Conversions / leads | Advantage+ only after a winning creative |
| LinkedIn Ads | B2B, talent, $5k+ ACV | Leads / pipeline | Expensive CPC; use document ads + tight titles |
| X / Twitter Ads | Dev tools, newsjacking | Follows / site visits | Conversion tracking often weak; use UTMs |
| Reddit Ads | Niche subs | Traffic / conversions | Interest + subreddit; native tone or it flops |
| TikTok Ads | Consumer, mobile, young ICP | Installs / traffic | Native UGC creative; no landing-page-first |
| Pinterest Ads | Consumer, visual, DIY | Traffic / sales | Rare for pure developer tools |
| Snapchat Ads | Youth consumer | Installs | Rare for B2B |
| Threads / emerging social ads | Consumer | Awareness | Treat as experimental |

## Default test recipes

Use these when the user has no preference.

**Under $500 total**
- 70% Google Search exact/phrase on 5–15 keywords
- 30% one newsletter or Reddit test
- Kill any ad group with 2× target CPA and 0 conversions after 40–80 clicks

**$500–5k**
- Search (core intent) + one social (Meta or LinkedIn by ICP) + one newsletter
- Daily caps per channel; weekly creative refresh
- Kill social if CTR < 0.4% (feed) or CPC > 3× search CPC with no trial

**$5k+**
- Search always-on + social scale on winning creative + 1–2 sponsorships
- Separate brand vs non-brand search
- Frequency cap remarketing at 3/week

## Kill criteria (always include)

| Signal | Action |
|--------|--------|
| 2× target CPA, no conversion | Pause ad group |
| CTR far below channel norm | Replace creative, keep targeting |
| High CTR, zero on-site conversion | Fix landing / offer, not ads |
| Policy reject | Rewrite claims; do not appeal with the same copy |
| Brand-safety complaint | Stop, document, downgrade intensity |

## Compliance

- No invented testimonials, fake scarcity, or competitor trademark bidding unless the user explicitly accepts the risk.
- Crypto, health, finance, and kids apps need extra policy review before any paid row is recommended.
- This catalog is a planner. Publishing requires the user's own ad accounts.
