# Agent notes

This repository is the **promoting-developer-apps** skill plugin.

When the user wants to promote an app or website, plan ads, pick a launch intensity, generate docs/video, raise funds, or sell an app or talent:

1. Read `skills/promoting-developer-apps/SKILL.md`
2. Load only the reference files that slice needs
3. Follow the deliverable templates in `skills/promoting-developer-apps/assets/`

Do not build a website, login, signup, user-account system, or admin console. The product is the marketplace skill. The host already identifies the person in the chat.
